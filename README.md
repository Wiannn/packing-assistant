# 3D 装箱辅助软件（packing-assistant）

面向实际装柜作业的集装箱装箱计算与可视化工具。纯前端单文件应用，无需安装、无需服务器，浏览器打开即用。

**在线使用：<https://wiannn.github.io/packing-assistant/>**

## 功能

- **3D 可视化装箱**：Three.js 实时渲染集装箱与货物，支持旋转 / 缩放 / 平移视角
- **自动装箱算法**
  - 全局 3D 极值点装载：从最深处向门口铺货，自动回填凹陷与缝隙
  - 水平 90° 旋转（不竖翻），符合实际装卸约束
  - 类别承重等级（纸箱 < 木箱 < 导轨）：上面货物的等级 ≤ 下面货物才能叠放，等级可在界面调整
  - 支撑覆盖率 ≥ 70% 判定：允许跨接缝、局部悬空，贴近真实装柜
  - 超长件（如导轨）「必装」优先：自动贴左右侧墙成列、轮流叠层，4 种沿长度方向的布局自动选优
- **手动模式**：拖拽货物换位、右击旋转 90°、碰撞自动推位、重力下落；箱外待装货可拖入箱内，箱内货也可拖出
- **装车指引**：按「最深处 → 门口、先底层后上层」的真实作业顺序逐步演示（自动满足支撑拓扑约束）
- **货物清单**
  - 尺寸 / 数量 / 颜色 / 类别 / 圆柱外观 / 必装，实时编辑自动保存（localStorage）
  - 多清单管理：另存 / 切换 / 删除，适合同时跟进多个装柜任务
- **统计**：容器容积、清单体积、已装体积、空间利用率
- **双向联动**：点 3D 货物定位清单行；悬停清单行高亮该组全部货物
- **方案导入导出**：JSON 格式，包含清单、集装箱尺寸与每件货物坐标

## 快速开始

1. 打开网页，在左侧「货物清单」录入货物（或「导入方案」载入已有 JSON）
2. 设置集装箱尺寸（内置 20GP / 40HC 预设）
3. 点 **自动装箱**，右侧 3D 视图显示方案；装不下的货物排在集装箱右侧外（半透明红边）
4. 用 **上一步 / 下一步** 查看装车顺序；切到 **手动模式** 微调
5. **导出方案** 存档，或换清单继续下一票

## 技术

- 单文件 HTML（[`装箱软件.html`](装箱软件.html)），原生 JavaScript + CSS
- [Three.js r137](https://unpkg.com/three@0.137.5/)（CDN 加载，需联网）
- 数据持久化：localStorage + JSON 文件导入导出

## 项目结构

```
index.html      入口页（跳转至主程序，用于 GitHub Pages）
装箱软件.html    主程序（全部功能在此）
packing.html    早期中间版本（已停止维护）
style.css, js/  早期模块版本残留（已停止维护）
```

## 本地使用

直接双击 `装箱软件.html` 即可（需联网加载 Three.js）。也可以部署到任意静态服务器。
